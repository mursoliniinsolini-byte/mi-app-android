EGG RUN - proyecto Android
Opcion A (sin instalar nada): sube esta carpeta a un repo de GitHub -> pestaña Actions -> "Build APK" -> descarga el artefacto EggRun-apk (app-debug.apk).
Opcion B: abre la carpeta en Android Studio -> Build > Build APK(s).


ADMOB (integración inicial)
- Se integró GMA Next-Gen SDK 1.7.0.
- Recompensado: revivir solo después de recibir la confirmación de recompensa de Google.
- Intersticial: al tocar REINTENTAR después de terminar una partida; máximo uno cada 90 segundos.
- USE_TEST_ADS está en true: se usan IDs de prueba oficiales mientras desarrollas.
- Antes de publicar, revisar privacidad/consentimiento y cambiar USE_TEST_ADS a false en MainActivity.java para activar tus unidades reales.
- No pulses anuncios reales durante pruebas.
